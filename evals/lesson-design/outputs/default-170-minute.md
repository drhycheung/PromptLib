## 5. Lecture Outline

| Lecture segment | Key ideas | Purpose in the lesson | Follow-up learner task |
|---|---|---|---|
| **1. What is assessment for?** (3 min) | Assessment serves two broad purposes: supporting learning (formative) and certifying attainment (summative). Neither purpose is inherently superior. | Establish conceptual anchor before examples | Learners flag one idea on their note frame |
| **2. Formative assessment defined** (4 min) | Key features: embedded in learning; generates feedback; no permanent grade required; informs next steps for teacher and learner. Example: a teacher uses class responses to a mini-quiz to re-teach a misunderstood concept. | Build accurate schema for LILO 1 | — |
| **3. Summative assessment defined** (4 min) | Key features: occurs after a learning period; judges cumulative attainment; typically graded; used for reporting or certification. Example: end-of-year public examination. | Build accurate schema for LILO 1 | Learners annotate: *"One thing I assumed was wrong"* |
| **4. The blurry boundary** (1 min) | The same task (e.g., a quiz) can be formative or summative depending on intent and use. Purpose and use, not format, define the type. | Pre-empt the most common misconception; scaffolds card sort | Activates higher-order thinking in card sort |
