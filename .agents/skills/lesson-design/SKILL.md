# Lesson Design

## Output language

Write the plan in the language the teacher used in the request, matching their script and level of formality, unless they explicitly ask for another language. This applies to every heading, table cell and sentence, including the template section titles, so a request written in Chinese receives a plan written in Chinese. Keep the English Bloom level names and add a translation in brackets when the plan is not in English. Keep the template structure and section order unchanged in every language.

## Purpose

Help a teacher design a coherent lesson in which intended learning outcomes, learning activities, formative assessment, timing and resources support one another through constructive alignment.

## Choose an operating mode

- Use **guided mode** by default. Develop the design one stage at a time, invite feedback, and wait for the teacher's confirmation before continuing.
- Use **complete mode** when the teacher explicitly requests a finished plan. Complete all stages in one response and identify any assumptions. Return exactly one final lesson plan; do not restate it or provide an unsolicited alternative version.
- If the teacher changes an earlier decision, revise the dependent outcomes, activities, assessment and timing before proceeding.

## Gather context

Obtain the following information before producing a final plan:

- topic and scope;
- discipline, cohort and relevant prior knowledge;
- lesson duration and timetable constraints;
- required resources or accessibility considerations;
- any existing learning outcomes or institutional requirements.

Ask only for information that is necessary and cannot be inferred safely from the request. When essential context is missing, ask a concise batch of questions rather than inventing it. If the teacher wants rapid ideation, proceed with clearly labelled assumptions.

## Workflow

### 1. Frame the lesson

Summarise the topic, learners, duration, constraints and the conceptual problem the lesson should address. Narrow an overly broad topic before proceeding.

### 2. Propose lesson intended learning outcomes

- Propose three to five LILOs unless the teacher specifies another number.
- Use observable, measurable action verbs.
- Do not use vague outcomes such as “understand”, “know about” or “be aware of”.
- Consult [the Bloom level guide](references/bloom-levels.md) before assigning levels, and use its sentence stems to phrase each outcome.
- Assign exactly one level from the 2001 revised Bloom taxonomy to each LILO: Remember, Understand, Apply, Analyse, Evaluate or Create. Do not use combined labels such as “Remember/Understand”. If an outcome contains verbs from different levels, rewrite it or use the highest level actually demanded by the task and assessment.
- Make the cognitive demand realistic for the available time.

### 3. Design formative assessment

- Propose engaging activities that generate observable evidence of learning.
- Prefer collaborative, authentic and constructivist tasks when they suit the context.
- State the evidence each activity produces and map it to the relevant LILO or LILOs.
- Explain how learners will receive feedback or use the evidence to revise their thinking.

### 4. Design teaching and learning activities

- Select activities that prepare learners to perform the assessment successfully.
- Keep the cognitive demand aligned with the target Bloom level.
- Specify the roles of the teacher and learners, the expected learner output and the resources required.
- Build in accessibility and learner-variation options when the context requires them, such as alternative formats for materials or additional processing time.
- Map each activity to the formative assessment it supports.
- Include an outline for lecture-based input only when it is necessary; do not use lecture as the default method.

### 5. Build the lesson sequence

- Allocate a specific time to every segment, including breaks.
- Use the requested duration. For the original 170-minute format, include two 10-minute breaks at approximately minutes 60 and 120.
- Do not add a scheduled break unless the teacher requests it or local policy requires it. An optional micro-pause is not a scheduled break and must be labelled as optional.
- Ensure that all segments, including breaks, add up to the stated duration.
- Include an orientation or activation, substantial learning activity, formative assessment, feedback and closure.

### 6. Check constructive alignment

Before presenting the final plan, verify that:

- every LILO is observable and supported by an appropriate Bloom level;
- every LILO has at least one aligned assessment activity;
- every activity contributes to a stated learning outcome or assessment need;
- the assessment evidence indicates whether each LILO has been achieved;
- the timing is realistic and internally consistent.

## Final output

Read [the lesson plan template](references/lesson-plan-template.md) before producing a final lesson plan. Include the lesson context, LILOs, formative assessment, lesson sequence, resources and an alignment check. In complete mode, keep progress commentary internal, return one final plan only, and end with a summary table linking each LILO to its assessment evidence and supporting activities. If a complete plan has already been presented, stop rather than repeating or expanding it.

## Final quality check

Before sending the plan, confirm all of the following:

- the plan is written in the teacher's language;
- the plan appears exactly once, with no restatement and no alternative version;
- section numbers run consecutively from 1, with no gap where an optional section was omitted;
- every LILO has exactly one Bloom level, and that level matches the action verb in the outcome;
- every time allocation, including breaks, sums to the requested duration, and any breakdown of the total by category is itself arithmetically correct;
- every LILO appears in the alignment check with its assessment evidence.

## Boundaries

- Do not use this skill to mark submitted student work.
- Do not use this skill to generate examination questions.
- Do not use this skill to design multi-lesson schemes or programme-level curricula; propose splitting the work into separate lessons instead.
- Do not invent institutional policies, learner information, research evidence or resource availability.
- Clearly distinguish teacher-provided requirements from suggested design choices.
